[목적] 4차시 모듈 두 개를 만들어줘. mywork/write.py 는 Claude API로 3줄 요약·제목 후보를 생성하고(계산은 하지 않는다),
       mywork/review.py 는 생성된 문장 속 숫자를 원본과 대조한다. 먼저 mywork/press_data.json 의 구조를 읽어 봐줘.

[입력] press_data.json 의 계산지표, 품목별지표, NLP분석결과(핵심키워드·주요문장), mywork/config.py 의 INDICATOR_UNITS

[출력] 아래 이름은 그대로 써줘(검증 코드가 이 이름을 쓴다).
[mywork/write.py]
- MODEL_NAME = "claude-sonnet-5-5", 모듈 전역 client(anthropic.Anthropic())
- SYSTEM_PROMPT — 역할(국가데이터처 보도자료 작성 담당자)과 제약(제공된 숫자만 사용, 숫자를 만들어내지 말 것, 객관적 서술)
- format_value(field, value) — 단위를 붙인 표기. 예) 총거래액 201250 → "201,250억 원", 1.5 → "1.5%"
- call_claude(prompt, system=SYSTEM_PROMPT, max_tokens=2000) — API를 한 번 호출해 응답 텍스트를 돌려준다.
- parse_json_response(response_text) — 응답에 코드펜스나 설명이 섞여도 JSON 객체·배열 부분만 찾아 파싱한다.
- build_summary_prompt(data) — 계산지표(format_value 표기)와 증감 방향, 핵심키워드, 주요문장을 넣은 요약 요청 프롬프트.
  Few-shot 예시 1개를 넣고, 출력 형식 {"삼줄요약": [3문장], "제목후보": [3개]} JSON으로만 답하게 한다.
- generate_summary(data) — build_summary_prompt → call_claude → parse_json_response 결과 dict
[mywork/review.py]
- find_unverified_numbers(text, data) — 문장 속 숫자 중 원본(계산지표·품목별지표 값)에 없는 숫자의 원래 표기 목록.
  콤마는 떼고 비교한다. 1~2자리 정수와 4자리 연도(1900~2100)는 대조에서 뺀다.
- verify_numbers(summary_text, source_data) — 근거 없는 숫자가 없으면 True

[★ 반드시 지킬 것]
- load_dotenv()를 anthropic.Anthropic()보다 먼저 호출한다.
- client.messages.create에 thinking={"type": "between_tools"}를 넣고 temperature는 넣지 않는다(이 모델은 거부한다).
- 응답은 content 중 type이 "text"인 블록만 모아 쓴다. stop_reason이 "refusal"이면 예외를 낸다.
- 증감률은 abs()로 부호를 떼고 "1.5% 증가" / "2.3% 감소"처럼 넣는다. 프롬프트에 "숫자는 적힌 표기 그대로, 새로 계산하지 말 것"을 명시한다.
- 원본의 음수(예: -3.5)는 문장에서 "3.5% 감소"로 쓰이므로 절댓값도 원본 숫자로 인정한다.

[끝나면] python -c "import mywork.write, mywork.review" 로 import만 확인하고(API는 부르지 마),
         ★ 조건 다섯 가지를 코드 어디서 처리했는지 짚어줘.
