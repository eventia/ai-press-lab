[목적] 9차시 함수를 추가해줘(기존 함수는 고치지 말 것). 리드문과 본문을 합친 초안을 공공 보도자료체로 통일하고,
       표기 검수 → 수치 교차 검증 → AI 감수의 3단계로 최종 확인한다. 먼저 mywork/press_data.json 의 헤드라인·본문을 읽어 봐줘.

[입력] press_data.json 의 헤드라인(리드문), 본문, 계산지표·통계해석결과·품목별지표·역대최대여부·최근3개월증감률,
       write.py 의 call_claude·parse_json_response·assemble_body, review.py 의 find_unverified_numbers, config.ISSUER

[출력] 아래 이름은 그대로 써줘(검증 코드가 이 이름을 쓴다).
[mywork/write.py]
- assemble_full_text(data) — 리드문 + 빈 줄 + 본문(assemble_body)
- unify_style(draft_text) — "{ISSUER} 보도자료 문체로 통일"하는 프롬프트로 call_claude 를 불러 결과를 돌려준다.
  객관적 서술체(~하였다, ~로 나타났다), 주관적 수식어(매우, 놀랍게도 등) 제거.
[mywork/review.py]
- check_formatting_errors(text) — 정규식 기반 표기 검수. 오류 설명 문자열 목록을 돌려준다. 잡을 것 세 가지:
  ① 숫자 바로 뒤 "억원" 붙여쓰기 ② 천 단위 콤마가 없는 5자리 이상 숫자 ③ "비중"의 증가·감소·확대·축소를 말하는데 문서에 "%p"가 없음
- cross_check_all_numbers(final_text, data) — {"통과": bool, "불일치수치": [...]}
- review_press_release(final_text, data) — 통계 보도자료 전문 감수자로서 원본 데이터(근거자료)와 보도자료를 대조해
  수치 오류·과장된 표현·문체 불일치·논리적 비약을 최대 5건 지적하게 한다. [{"유형", "위치", "지적사항"}] JSON 배열(문제 없으면 []).

[★ 반드시 지킬 것]
- 문체 통일 프롬프트에 "사실과 수치는 절대 변경 금지(숫자·콤마·단위 그대로)", "단락 구분(빈 줄) 유지",
  "설명이나 머리말 없이 수정된 본문만 출력"을 넣는다.
- 콤마 검사는 "201,250"이나 "8.7" 같은 정상 표기, 4자리 연도를 오류로 잡으면 안 된다.
- cross_check_all_numbers 는 4차시 find_unverified_numbers 를 재사용한다(요약과 최종본에 같은 기준).
- AI 감수 프롬프트에는 근거자료(계산지표·통계해석결과·품목별지표·역대최대여부·최근3개월증감률 중 있는 것)를 JSON으로 넣는다.
- 감수 응답 파싱에 실패하면 예외 대신 [{"유형": "감수 응답 파싱 실패", "위치": "-", "지적사항": 안내 문장}]을 돌려준다.
- review.py 가 write.py 를 import 한다(반대 방향은 금지 — 순환 import).

[끝나면] python -c "import mywork.write, mywork.review" 로 import만 확인하고(API는 부르지 마),
         ★ 조건 여섯 가지를 코드 어디서 처리했는지 짚어줘.
