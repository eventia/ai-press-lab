# 실습 데이터

> **이 폴더의 수치는 실습용으로 만든 가상 데이터입니다. 실제 통계가 아니며, 인용하거나 보도에 사용할 수 없습니다.**
> 문서 안의 기관명(국가데이터처)과 지표명(온라인쇼핑 거래액)은 실습 상황을 실감 나게 하려고 빌려 쓴 것일 뿐, 해당 기관이 공표한 자료가 아닙니다.

| 파일 | 쓰는 차시 | 내용 |
| --- | --- | --- |
| `raw_202601.json` | 2차시~ | Open API 응답을 저장해 둔 것으로 가정한 원본. 원문에 일부러 불규칙한 공백·괄호 주석·붙여 쓴 단위·개조식 종결을 넣었습니다 |
| `온라인쇼핑동향_2026_01.xlsx` | 7·10차시 | 같은 원본으로 만든 엑셀 원자료(`요약`·`이력` 시트) |
| `온라인쇼핑동향_2026_01.pdf` | 7·10차시 | 같은 원본의 원문 문장을 담은 PDF |

- 금액 단위는 모두 **억 원**입니다.
- 세 파일의 숫자는 서로 맞도록 만들었습니다(예: 월별이력으로 다시 계산한 전월 대비 1.5%, 전년 동월 대비 8.7%가 계산지표와 같음).
- 실습 폴더의 `data\` 에 복사해서 씁니다. 원본 파일은 수정하지 않습니다.
