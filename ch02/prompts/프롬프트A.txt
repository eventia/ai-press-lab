[목적] 2차시 정제 모듈을 만들어줘. mywork/config.py 에는 데이터 항목 정의(데이터 딕셔너리)를,
       mywork/clean.py 에는 원본 자료를 정제·표준화·구조화하는 함수를 둔다. mywork/__init__.py 는 빈 파일로 만든다.
       먼저 data/raw_202601.json 을 읽어 구조를 확인해줘.

[입력] data/raw_202601.json (제목·기준연월·공표일자·보안등급·계산지표·핵심내용·원문·품목별지표·월별이력)

[출력] 아래 이름은 그대로 써줘(검증 코드가 이 이름을 쓴다).
[mywork/config.py]
- DATA_DICTIONARY: {항목명: {"영문", "타입", "단위", "등급", "정의"}}. 항목과 등급은
  총거래액(억 원, 필수), 전월대비증감률(%, 필수), 전년동월대비증감률(%, 필수),
  품목별지표(억 원, %, 선택), 공표일자(-, 참고), 자료출처(-, 참고). 정의는 한 문장.
- REQUIRED_FIELDS(등급이 "필수"인 항목명 목록)와 INDICATOR_UNITS({필수 항목명: 단위})는 DATA_DICTIONARY에서 뽑아 만든다.
- INDICATOR_NAME = "온라인쇼핑 거래액", ISSUER = "국가데이터처", PRIMARY_INDICATOR = "총거래액"
[mywork/clean.py]
- mask_sensitive_info(text): 주민등록번호는 "******-*******", 휴대전화는 "010-****-****"로 가린다.
- standardize_date(value): "2026.3.1", "2026/03/01", "2026-3-1", "2026년 3월 1일" 같은 날짜를 YYYY-MM-DD로. 모르는 형식은 그대로.
- clean_text(text): 정제(연속 공백·줄바꿈 → 공백 하나, 앞뒤 공백 제거, "(주:…)" 괄호 주석 제거) →
  표준화(숫자 뒤 "억원"→"억 원", "백만원"→"백만 원", "전월대비"→"전월 대비", 문장 끝 "하였음."→"하였다.") → 마스킹 순서.
- clean_and_structure(raw): 표준 구조 dict를 새로 만들어 돌려준다.
  {"문서정보": {"제목", "공표일자"(표준화), "자료출처"(없으면 "공공데이터포털 Open API"), "기준연월"(없으면 ""),
               "지표명"(없으면 INDICATOR_NAME), "보안등급"(없으면 "미확인")},
   "계산지표", "핵심내용", "원문"(clean_text 적용)} + raw에 있으면 "품목별지표", "월별이력", "역대최대여부", "최근3개월증감률"

[★ 반드시 지킬 것]
- 휴대전화 앞자리 010, 011, 016, 017, 018, 019 여섯 가지가 모두 가려져야 한다(특히 010). 지역번호(02-123-4567)는 그대로 둔다.
- 입력 raw는 절대 바꾸지 않는다(원본 보존). 결과에 넣는 dict·list는 복사본이어야 한다.
- 계산지표는 다시 계산하거나 바꾸지 않는다. 정제는 구조만 표준화한다(계산은 5차시 stats.py가 담당).
- 표준 구조의 키 이름은 한글 그대로 쓴다.
